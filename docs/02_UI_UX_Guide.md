# HireNext UI/UX Guide

## Design Style

HireNext should look like a premium SaaS recruitment platform.

The UI should be inspired by:

- Workable
- Greenhouse
- Lever
- Vercel Dashboard
- Stripe Dashboard

The interface should be modern, minimal, responsive, and professional.

Avoid Bootstrap styling.

Use:
- Tailwind CSS
- Shadcn UI
- Framer Motion
